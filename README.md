# ⚒ LEGIONFORGE

**Автономная серверная платформа World of Warcraft: Legion — строго 7.3.5 (Client Build 26124).**

Полный комплект «под ключ»: пропатченное и ребрендированное ядро C++, кастомные игровые системы,
умные лаунчеры, портативная среда сборки, GUI-менеджер, веб-панель администратора и документация.

## Быстрый старт

```bat
1. Положите дампы БД в   /sql/base/    (auth.sql, characters.sql, world.sql, hotfixes.sql)
2. Положите карты в      /server/data/ (cameras, dbc, db2, gt, maps, mmaps, vmaps)
3. Запустите             START.bat     (среда -> исходники -> БД -> компиляция -> сервер)
4. Запустите             PANEL.bat     (веб-панель: http://127.0.0.1:3000)
```

## Что было починено

Полный перечень найденных дефектов и внесённых изменений — **docs/FIXES_RU.md**.
Ключевое:

* все `.bat`/`.ps1` имели LF-окончания строк (`* text=auto` в `.gitattributes`) —
  именно поэтому пакетные файлы не работали; теперь закреплено `eol=crlf`;
* отсутствовал `project.json`, который читает `tools/bootstrap.ps1`, — из-за этого
  падал любой лаунчер; манифест создан;
* отсутствовал триггер `legionforge.bin`; создан, и `PANEL.bat` больше не считает его обязательным;
* login-сервер 7.3.5 — это `bnetserver`, а не `authserver`; проверка готовности сборки исправлена;
* панель собиралась в `web_panel/`, хотя `bootstrap.ps1` собирает её из корня — исходники перенесены в корень;
* `worldserver.conf`/`bnetserver.conf` указывали на несуществующие БД (порт 3306, имена `auth`/`world`),
  приведены к тому, что реально создаёт `bootstrap.ps1` (порт 3307, префикс `legion_`).

После клонирования выполните один раз `git add --renormalize .`, чтобы Git закрепил CRLF.

# /tools/dotnet — портативная утилита LEGIONFORGE

Каталог заполняется автоматически скриптом `tools/download_tools.ps1`
(вызывается из `START.bat` на шаге 1), если утилита отсутствует.

Ничего не устанавливается в систему: всё распаковывается внутрь этой папки,
поэтому платформа остаётся на 100% портативной — её можно переносить
целиком на флешке или в облако.

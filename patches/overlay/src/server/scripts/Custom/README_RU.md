# LegionForge — кастомные C++-скрипты (чистая дельта)

Здесь лежат **только новые изолированные файлы**. Они не входят в апстрим
LegionForgeCore и не перезаписывают его код — это и есть «чистая дельта» наших
изменений относительно оригинала. Каждый модуль можно отключить по одному,
не ломая остальной функционал.

## Файлы

| Файл | Модуль | Что делает |
|------|--------|-----------|
| `LegionForge_Config.h` | общее | ID валюты (1533), лимиты (1200 / 1000), диапазоны предметов и NPC |
| `LegionForge_ItemTome.cpp` | Забытые способности | Учит удалённый спелл по `SpellID[0]` тома, **проверяя класс** по `AllowableClass` |
| `LegionForge_ItemUpgrade.cpp` | Улучшение предметов | Концентрат силы (+5 ilvl легендарке, до 1200) и Эссенция закалки (985 → 1000) |
| `LegionForge_VendorNPC.cpp` | Торговец | NPC-сборщик: продаёт реагенты и томы за Сущности, открывает подсказку по магазину |
| `LegionForge_OnlineReward.cpp` | Бонус за онлайн | Раз в час выдаёт +50 Сущностей всем игрокам онлайн |
| `LegionForge_BrokenQuests.cpp` | Компенсация квестов | Мгновенно завершает и выдаёт награду за известные битые квесты |
| `LegionForge_WorldBoss.cpp` | Мировые боссы | Одна компактная ИИ-модель для всех 60 боссов |
| `LegionForge_Loader.cpp` | регистрация | Вызывает `AddSC_*` всех модулей одной функцией |
| `PATCH_BattlePayEssence_RU.md` | оплата магазина | Точечный патч ядра: магазин списывает Сущности вместо доната |

## Интеграция (один шаг, полностью обратимый)

Скрипты написаны под стандартный скриптовой API LegionForgeCore/LegionForgeCore.
Чтобы собрать их вместе с ядром:

1. Скопируйте файлы `LegionForge_*.cpp` и `LegionForge_Config.h` в дерево
   скриптов ядра, например в `src/server/scripts/Custom/` (LegionForgeCore
   автоматически компилирует всё, что лежит в `Custom/`).
2. Вызовите `AddSC_LegionForge_Custom()` один раз из загрузчика скриптов ядра
   (в `src/server/scripts/Custom/...` или в общей функции `AddScripts()`).
3. Соберите ядро обычным способом (`START.bat` → Build).

**Откат:** удалите один вызов `AddSC_LegionForge_Custom()` — и сборка снова
станет на 100% апстримной. Никакой upstream-файл при этом не изменяется.

## Почему скрипты не копируются в ядро автоматически

Запускатор намеренно **не** пишет непроверенный C++ в `server/source`, чтобы
штатная сборка (`START.bat` → Build) всегда оставалась зелёной: апстрим-ядро +
моды. Интеграция нашей дельты — это один осознанный шаг администратора
(см. выше), при желании с адаптацией под конкретную ревизию ядра.

## Имена скриптов (ScriptName) в базе

Эти имена проставлены в `custom/sql/custom_database.sql` и
`custom/sql/world_bosses.sql` и должны совпадать со строками-конструкторами
скриптов выше:

- `item_legacy_tome` — томы способностей
- `item_upgrade_concentrate` — Концентрат силы
- `item_upgrade_endgame` — Эссенция закалки
- `npc_legionforge_vendor` — торговец-сборщик
- `npc_world_boss_generic` — все мировые боссы
- `legionforge_online_reward`, `legionforge_broken_quests` — World/Player-скрипты

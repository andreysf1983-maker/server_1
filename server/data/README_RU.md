# /server/data/ — клиентские данные 7.3.5.26124

Скопируйте сюда папки с вашего локального компьютера (извлечение из CASC клиента 7.3.5.26124):

```
/server/data/
├── cameras/
├── dbc/
├── db2/
├── gt/
├── maps/
├── mmaps/
└── vmaps/
```

В `worldserver.conf` путь задан как `DataDir = "../../data"` (относительно `/server/bin`).
Без карт сервер запустится, но телепорты, коллизии и поиск пути работать не будут.
